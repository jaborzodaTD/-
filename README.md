# METRO CITY: REBORN

**A browser city-builder by JABORZODA FAYZALI.**

## Play
Open `index.html` in a modern browser, or enable GitHub Pages in repository settings and choose the `main` branch with `/(root)` as the source.

## Features
- Build roads, residential, commercial and industrial zones.
- Place parks, power plants, water facilities, schools, hospitals and police stations.
- Manage the city budget, population, jobs, happiness and utilities.
- Upgrade buildings, demolish structures, rename your city and save progress locally.
- Responsive controls for phones and desktop browsers.

## Notes
This is a playable single-player browser prototype. Save data is stored in the browser's local storage on the current device. Online multiplayer, user accounts and shared cloud saves are not implemented yet.
